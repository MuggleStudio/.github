# MuggleStudio

**让想法成为好用、有趣的作品。**

An independent studio bringing ideas to life through thoughtful design and reliable engineering.

## 关于我们

MuggleStudio 是一个独立创作与开发工作室。我们保持好奇，探索不同领域、平台与产品形态，将想法变成可以使用、体验和分享的作品。无论做什么，我们都关注具体的使用场景，从交互细节到工程实现，持续打磨。

## 从想法到作品

| 环节 | 关注点 |
| --- | --- |
| 探索 | 从日常需求与新想法出发，尝试不同的技术和表达方式 |
| 设计 | 明确使用场景，让功能、交互与视觉形成完整体验 |
| 实现 | 将设计、开发、验证与迭代连接起来，兼顾体验和长期维护 |

## 我们的工作方式

- **从体验出发**：明确用户要完成的事情，让界面和操作服务于目标。
- **重视可靠性**：通过与改动相匹配的测试和实际运行验证功能。
- **持续打磨**：从可用的完整流程开始，根据反馈逐步完善。
- **尊重隐私**：关注数据的收集、存储和使用边界，清楚说明产品行为。

## 交流与协作

具体产品的介绍、使用说明和反馈方式以对应项目的 README 为准。报告问题时，请提供运行平台、版本和复现步骤；提出建议时，请说明使用场景与期望体验。

提交代码前，请先阅读项目的开发指南，并在 Pull Request 中说明改动目的和验证结果。
