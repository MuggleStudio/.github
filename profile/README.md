# MuggleStudio

**用心打磨移动应用与益智游戏。**

An independent studio crafting mobile apps and puzzle games with thoughtful design and reliable engineering.

## 关于我们

MuggleStudio 是一个独立开发工作室，围绕移动应用与益智游戏开展产品设计和开发。我们关注具体的使用场景，从交互细节到工程实现，持续打磨产品体验。

## 我们关注的方向

| 方向 | 关注点 |
| --- | --- |
| 移动应用 | 面向 Android 与 iOS，围绕日常需求设计清晰、易用的功能 |
| 益智游戏 | 打磨规则、操作反馈与游戏节奏，让玩家轻松上手 |
| 产品与工程 | 将设计、实现、验证与迭代连接起来，兼顾体验和长期维护 |

## 我们的工作方式

- **从体验出发**：明确用户要完成的事情，让界面和操作服务于目标。
- **重视可靠性**：通过与改动相匹配的测试和实际运行验证功能。
- **持续打磨**：从可用的完整流程开始，根据反馈逐步完善。
- **尊重隐私**：关注数据的收集、存储和使用边界，清楚说明产品行为。

## 交流与协作

具体产品的介绍、使用说明和反馈方式以对应项目的 README 为准。报告问题时，请提供运行平台、版本和复现步骤；提出建议时，请说明使用场景与期望体验。

提交代码前，请先阅读项目的开发指南，并在 Pull Request 中说明改动目的和验证结果。
